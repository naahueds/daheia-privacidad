# Política de privacidad de Daheia

Este repositorio publica la política de privacidad de la aplicación Daheia mediante GitHub Pages. La página principal es `index.html`.

- Sitio: https://naahueds.github.io/daheia-privacidad/
- Archivo publicado: `index.html`

La política describe el almacenamiento local, la publicidad de Google AdMob y los canales de contacto de privacidad.
